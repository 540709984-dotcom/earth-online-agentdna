# 首次 GitHub 发布前检查

- [ ] 确认仓库名、维护者署名和许可证与发布意图一致。
- [ ] 逐页确认没有私有 Obsidian 文本、客户资料、账号、token、内网地址、原始 trace 或未授权图片。
- [ ] 逐条点击研究报告里的关键链接，确认来源与表述仍一致。
- [ ] 在 WorkBuddy 当前客户端导入至少一支 Skill，保存加载成功的真实证据。
- [ ] 跑 `examples/fde-handoff/`，确认能拦住无来源的30%数字并区分 received、verified、accepted。
- [ ] 用一项低风险真实任务跑单代理基线与有限协作组，公开成本、时间、失败与限制。
- [ ] 仅在通过人工验收后把 `v0.1.0-draft` 改为可发布版本。

检查通过不替代发布者的最终判断；GitHub发布、对外发送和平台市场上架都属于独立外部动作。
